# 🧠 QuizMaster - Desafio do Conhecimento

Um jogo de perguntas e respostas interativo desenvolvido em **Python** com a biblioteca **PyQt6**. O projeto conta com uma interface moderna, animações, sistema de ranking e um banco com 100 perguntas aleatórias.

## 🚀 Funcionalidades
- **Interface Moderna:** Tema escuro com efeitos de brilho (neon) e transições suaves.
- **Cadastro de Jogador:** O jogador insere seu nome antes de começar.
- **Quiz Dinâmico:** A cada partida, 10 perguntas aleatórias são sorteadas de um banco com 100.
- **Feedback Visual:** As respostas corretas ficam verdes e as erradas ficam vermelhas.
- **Ranking Salvo:** As melhores pontuações são salvas em um arquivo JSON e exibidas no pódio (Ouro, Prata e Bronze).
- **Opção de Reset:** É possível zerar o ranking a qualquer momento.

## 🛠️ Tecnologias Utilizadas
- [Python 3](https://www.python.org/)
- [PyQt6](https://pypi.org/project/PyQt6/) (Interface Gráfica)
- JSON (Armazenamento local de dados)
